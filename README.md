# הסיפור של השיר

האתר בעברית ובאנגלית (מתג בראש העמוד). שיר שאינו בשפת האתר מקבל מיד חלונית תרגום: כתוביות מתורגמות בנגן, תקציר המשמעות, וקישורים לתרגומים מורשים.

**הוספת שיר:** מדביקים קישור מ-YouTube או מ-Vimeo בתיבה שבראש הספרייה. השם והמבצע נטענים אוטומטית, ועמוד השיר נפתח מיד. את הסיפור, המשמעות, הקאברים וההסבר בשיחה ממלאים עם Claude Code בסקילים `explore-song` ו-`song-explainer-notebooklm`.

אתר סטטי (HTML, CSS ו-JavaScript בלי שרת) לספריית שירים אישית. כל שיר מקבל עמוד אחד עם:

- נגן מתוך YouTube או Vimeo (האתר לא שומר קובצי שמע)
- הסיפור של השיר והיוצרים, במילים שלנו
- הסבר-שיחה של 2 דקות מ-NotebookLM (שדה `explainer` בשיר)
- לימוד בלופ: קטע מוגדר, הפסקה בין חזרות, מספר חזרות ומהירות איטית
- כתוביות: של YouTube או Vimeo בשפה שנבחרה, או קובץ LRC/SRT אישי שנשמר רק בדפדפן
- מילים ותרגום דרך אתרים מורשים (Genius, שירונט, LyricsTranslate, Google Translate)
- קאברים: ניגון בתוך העמוד, חיפוש ב-YouTube וב-SecondHandSongs
- תווים ואקורדים לפסנתר, גיטרה ותופים דרך MuseScore, Chordify, Ultimate Guitar, Tab4u ו-Songsterr

## קבצים
- `songs.js` – ספריית השירים. מבנה כל שיר מתועד בראש הקובץ.
- `app.js` – כל הלוגיקה (ניווט, נגן, לופ, כתוביות, טופס הוספה).
- `styles.css`, `index.html`.

## הרצה
פותחים את `index.html` בדפדפן, או מעלים את התיקייה ל-GitHub Pages (חינם).

## זכויות יוצרים
לא מוסיפים ל-`songs.js` מילים מלאות או תווים מלאים. רק קישורים, טקסט מקורי שכתבנו, ונקודות זמן.

## בהמשך
שמירה משותפת של שירים שמשתמשים מוסיפים (למשל Supabase או Firebase בתוכנית החינמית). בינתיים שירים חדשים נשמרים בדפדפן ומיוצאים לקובץ JSON.
